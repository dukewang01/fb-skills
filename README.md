# fb-skills

酒店餐饮（F&B）合规与运营技能集。可直接放入 agent 的 skills 目录使用。

## 技能清单

### menu-compliance-review — 菜单合规审查
收到菜单、台卡、宴会菜单、BEO 菜单、送餐菜单或餐饮宣传文案时使用。

- **依据**：集团《菜单描述-合规审查清单》12 条 + 《中华人民共和国广告法》《反不正当竞争法》
- **输出**：固定格式的问题清单表（位置 / 原文 / 违反条款 / 级别 / **建议用词**），表后附"须补的标识清单"
- **级别**：🔴 必改 ｜ 🟠 建议改或需确认 ｜ 🟡 提示
- **纪律**：必须给具体替换词；拿不准标"需确认"（误报比漏报更伤信任）；中英都看
- **流程提醒**：改后须由餐饮经理/餐饮总监/行政总厨在集团食品安全系统创建审阅任务，由卫生专员完成审阅

配套参考：
- `references/checklist.md` —— 12 条逐条判定要点与常见原文示例
- `references/banned-words.md` —— 广告法四类禁用语完整词表 + 替换词对照
- `references/special-ingredients.md` —— 特殊食材与药食同源判定口径

## 使用方式

把对应技能目录放进 agent 的 skills 路径即可；技能文件为纯 Markdown，不依赖任何外部服务。

## 说明

本仓库内容为通用模板，不含任何具体门店、品牌、人员或经营数据。
