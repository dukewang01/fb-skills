# 餐配酒 · 通用版

把菜单与酒水单接起来：**先看菜，再看菜系，最后用本店酒单收口。**

⭐ **使用顺序**：一节判断轴 → 二节菜系目录 → 三节非葡萄酒 → 四节套餐 → 五节单杯 → 六节话术 → **末节查本店配置** → 十节输入数据规范 → 十一节交付前自检。

⚠️ **本文分两层**：一～六节是**知识**（不随店变，可迁移）；末节是**配置**（各店不同、会变，用时先核）。**不要把配置写进知识层。**

🤖 **机器可读层**：`rules.yaml` 是本文件判断轴、裁决顺序、违例规则与价格口径的可执行版本。**做酒单批量体检、或让 agent 自动出方案时以它为准**，不要用自然语言复述阈值。

## 一、判断轴（九条，先全过一遍）

**看菜（决定选什么酒）**
1. **脂肪量**：高 → 可上单宁/重酒（红肉、鸭、鹅肝、龙虾）；低 → 轻酒（白身鱼、蔬菜、贝类）
2. **鲜味 umami**：高 → 避开单宁（单宁遇鲜出金属腥）→ 清酒/干白
3. **辣度**：高 → 避开高单宁 **且避开高酒精**（两者都放大辣）→ 微甜/起泡/低度
4. **酸度**：高 → 酒也要有酸或微甜，否则酒被菜压成水
5. **甜度**：高 → **酒必须比菜更甜**，否则酒显苦（甜点配干酒 = 经典错误）

**看服务（决定怎么上）**
6. **上酒温度**：单宁重太冷会涩；起泡/清酒要冷
7. **上酒顺序**：先轻后重、先干后甜、先起泡后静止
8. **杯装/瓶装**：先确认客人预算与单杯意愿 —— 并非每款都能单杯点

⭐ 一句话：**单宁只跟脂肪做朋友。** 遇到鲜、辣、酸、甜，它全是减分项。

9. **胶质 / 黏口感**（v1.1 新增）：高 → 中重质感干白、轻中单宁红；**不能按「低脂 = 轻酒」推**
   - 高胶质菜：花胶、海参、鱼唇、蹄筋、牛筋、猪手、鲍汁扣类、浓汤（老火例汤除外）
   - 原理：胶质不是脂肪，但**口感厚、包舌** → 轻酒被压成水；胶质又不像脂肪能结合单宁 → 重单宁显涩。**中段位置的酒**（半干雷司令、过桶霞多丽、黑皮诺、桑娇维塞）才是正解。
   - 参考：花胶/海参 → 过桶霞多丽、半干雷司令、轻中单宁黑皮诺；蹄筋/猪手 → 黑皮诺、桑娇维塞；鲍汁扣 → 过桶霞多丽、白中白香槟


### ⭐ 九条轴打架时的裁决顺序（v1.1 新增 —— 没有这条，两个人配同一道菜会配出两样）

按**从上到下**判，先命中先收口：

| 顺位 | 轴 | 为什么它优先 |
|---|---|---|
| 0 | **忌配（硬规则）** | 见 `rules.yaml` 的 `forbidden`：重单宁×鲜、重单宁×辣、烈酒×辣、干酒×甜品、河鲜×红 —— 命中即排除，不再往下判 |
| 1 | **鲜味 umami** | 鲜最容易被单宁毁掉，且高鲜菜几乎都同时低脂 |
| 2 | **辣度** | 辣会放大一切错误（单宁的涩、酒精的灼），用错方向不可挽回 |
| 3 | **甜度（菜品）** | 甜品必须配更甜的酒，这条压倒脂肪 |
| 4 | **胶质** | 只用于修正「低脂」的误判方向 |
| 5 | **脂肪量** | 前四项都不命中时，脂肪量才是主判据 |
| 6 | 酸度 / 温度 / 顺序 / 杯装 | 属「怎么上」，不改选酒结论，只改呈现 |

⚠️ **一道菜同时高鲜 + 高辣时**（如 蒜蓉辣椒炒海鲜）：取**交集** —— 既「避单宁」又「避高酒精」，答案是**有酸度的微甜起泡 / 半干雷司令 / 啤酒 / 清酒**，不是「挑一个轴听」。

## 二、菜系目录

### 红肉 Red Meat

| 部位 / 菜 | 配什么 |
|---|---|
| 菲力（最瘦）| 轻单宁：梅洛、黑皮诺、品丽珠 |
| 眼肉 / 西冷（最肥）| 重单宁：赤霞珠、西拉、内比奥罗 |
| T 骨 / 意式牛排 | 桑娇维塞 |
| 干式熟成牛排 | 丹魄、里奥哈 Reserva（皮革/烟草调呼应）|
| 烤肉 / 炭烤 | 马尔贝克、仙粉黛（烟熏感）|
| 羊肉（有羶味）| 更重单宁：赤霞珠、西拉、丹魄 |

⭐ **越瘦的肉配越轻的单宁**；熟度越高汁水越少，单宁越无处依附 → 全熟配重单宁会显干涩。
⭐ **酱汁定酒，不是肉定酒**：黑胡椒汁↔西拉（同有胡椒香）；红酒汁↔黑皮诺/桑娇维塞（同源）；蓝芝士↔波特；青酱↔长相思（草本对草本）；奶油酱↔过桶霞多丽（黄油呼黄油）。

### 海鲜 Seafood

**核心冲突：海鲜 + 单宁 = 金属腥味**（"红酒配鱼有铁锈味"的原理）

| 类型 | 配什么 |
|---|---|
| 白身鱼 / 清蒸 | 长相思、阿尔巴利诺、绿维特利纳 |
| 生蚝 / 贝类 | 干型雷司令、香槟、绿维特利纳 |
| 龙虾 / 蟹 / 奶油酱 | 过桶霞多丽、白中白香槟 |
| 鱼子酱 | 香槟、冰镇伏特加 |
| 三文鱼 / 吞拿鱼（脂肪多）| **黑皮诺**（唯一能配鱼的常见红酒）|
| 炭烤 / 重味 | 桃红、轻单宁黑皮诺 |

⚠️ **避开**：赤霞珠 / 西拉 / 马尔贝克 / 任何重单宁红。
⚠️ 红肉与海鲜同桌 → **分开配酒**（两杯/两瓶），不要一瓶到底。
⚠️ 河鲜（白鱼/银鱼/白虾）属"鲜"，只能白或清酒，不上红。

### 中餐 Chinese

**难点：一桌多菜、一味型一酒 → 一瓶很难配全桌。** 解法：**按主导味型选，不按菜选**。

| 味型 | 配什么 |
|---|---|
| 咸鲜 / 清蒸 | 雷司令、长相思 |
| 红烧 / 酱烧（甜咸）| 半干雷司令、黑皮诺 |
| 糖醋 / 咕噜（酸甜）| 雷司令、琼瑶浆（稍甜能压酸）|
| 麻辣 / 川湘 | 微甜雷司令、桃红、啤酒 |
| 蒜香 / 葱姜 | 长相思、阿尔萨斯白 |
| 火锅 / 汤类 | 啤酒、起泡、清爽白 |
| 烧烤 / 油炸 | 起泡、清爽白、轻红 |

⭐ 辣菜不配高单宁高酒精；椰奶/咖喱类不配重单宁。
⭐ **中餐最优解常是「一白一红」**：白先上配凉菜/清蒸/蔬菜，红配红烧肉/牛排类。

### 日料 Japanese

**核心：日料讲究"不抢味" —— 清酒其实比葡萄酒更配。**

| 类型 | 配什么 |
|---|---|
| 刺身 / 寿司 | 纯米大吟酿、香槟、干型雷司令 |
| 天妇罗 | 香槟、干型雷司令、纯米酒 |
| 烤物 / 煮物 | 纯米酒、阿尔萨斯白、绿维特利纳 |
| 金枪鱼 / 烤鱼 | 黑皮诺（轻单宁）|
| 梅酒 / 烧酒 | 日料特有，清口用 |

⭐ **清酒的「旨味 umami」能呼应鱼的鲜** —— 葡萄酒做不到。
⚠️ **酱油会放大单宁** → 寿司配红酒容易发苦；橡木桶重的霞多丽会盖住刺身的细节。
⚠️ 清酒温度：大吟酿冷饮 10–15°C、纯米常温或微温、本酿造可热燗 40–50°C。

### 禽类 Poultry

- 烤鸡 / 火鸡 → 博若莱、轻霞多丽
- 鸡蛋类菜肴 → 起泡（尤其香槟）
- 鸭胸 / 鸭腿 → **黑皮诺**（经典）；烤鸭可配轻单宁红
- 鹅肝 → **甜白**（甜与肥的经典对冲）

### 猪肉 Pork

- 猪排 / 烤肉 → 干雷司令、黑皮诺
- 叉烧 / 蜜汁 → 果味红（佳美娜、仙粉黛）
- 火腿 / 风干肉 → 雪莉 Fino、起泡

### 蔬菜 / 素食 Vegetarian

- 难配：蔬菜的苦与土腥很能打单宁
- 首选 **长相思 / 绿维特利纳 / 干雷司令**；烤蔬菜可配桃红
- ⚠️ 醋汁沙拉会打单宁 → 配长相思/干雷司令，不配红

### 其他菜系（香料系 / 奶椰系）

- 印度（香料重）→ 雷司令 / 琼瑶浆 / 桃红；⚠️ 不配重单宁
- 泰越（酸辣 + 香茅）→ 雷司令 / 琼瑶浆 / 起泡
- 韩餐（烤肉）→ 黑皮诺 / 烧酒；泡菜 → 雷司令
- 东南亚 / 咖喱（椰奶 + 香料）→ 琼瑶浆 / 微甜雷司令
- 墨西哥（辣 + 酸）→ 桃红 / 啤酒

### 芝士 Cheese

- 蓝芝士 → **波特 / 甜白**（经典）
- 硬芝士（切达 / 帕玛森）→ 赤霞珠 / 茶色波特
- 山羊芝士 → 长相思 / 阿尔萨斯白

### 甜点 Dessert

⚠️ **铁律：酒必须比甜点更甜**，否则酒显苦。
→ 甜白 / 冰酒 / 波特 / Moscato d'Asti

### 燕鲍参肚 / 花胶 / 炖汤（v1.1 新增 · 高端干货线）

**本类特征：低脂、高鲜、高胶质、价高。** 三个判据打架 → 按一节裁决顺序，**鲜 > 胶质 > 脂肪**。

| 菜 | 配什么 | 理由 |
|---|---|---|
| 海参（葱烧 / 鲍汁扣 / 凉拌）| 半干雷司令、过桶霞多丽；清酒纯米 | 高鲜低脂，**永不上重单宁** |
| 鲍鱼（清蒸 / 蚝皇 / 鲍汁）| 白中白香槟、过桶霞多丽、半干雷司令 | 高鲜 + 中等胶质 |
| 花胶 / 鱼唇 / 鱼肚 | 过桶霞多丽、半干雷司令、轻中单宁黑皮诺 | 胶质认「中段酒」 |
| 燕窝（甜）| **Moscato d'Asti / 甜白 / 冰酒**（走甜品铁律）；咸口燕窝配半干白 | 甜口按第 3 轴 |
| 浓汤 / 花胶鸡汤 / 佛跳墙 | 过桶霞多丽、半干雷司令、陈年香槟 | 胶质 + 鲜 |
| 上汤 / 清汤 / 老火例汤 | 绿维特利纳、干型雷司令 | 清汤走清爽白 |
| 蹄筋 / 牛筋 / 猪手 | 黑皮诺、桑娇维塞、半干雷司令 | 胶质认中段 |
| 干鲍 / 溏心鲍 | 陈年香槟、过桶霞多丽 | 高鲜高胶质，宁白不红 |

⚠️ **本类绝不允许把「重单宁红」当高档感推给客人** —— 「贵 ≠ 配」在这里最容易翻车。
⚠️ 燕鲍参多是**位上菜、份量小**，按「一口一口喝」估量：**用单杯比开瓶合理**（见五节）。
⚠️ 燕窝/花胶**甜品化**（冰糖炖）时按甜品铁律处理，不按食材本类处理。

### 烧味 / 烧腊（v1.1 新增 · 粤式）

**本类特征：皮脆油香 + 挂糖挂酱（甜咸）+ 常配酸梅酱/冰梅酱。** 判据：**甜咸酱 > 油香** → 果味、轻中单宁、半干白。

| 菜 | 配什么 |
|---|---|
| 烧鹅 / 烧鸭 | 黑皮诺、佳美（博若莱）、半干雷司令；配酸梅酱时走果味红 |
| 叉烧 / 蜜汁叉烧 | 果味红：佳美娜、仙粉黛、薄若莱；半干雷司令 |
| 烧腩仔 / 烧肉 | 半干雷司令、黑皮诺；皮脆油重可上轻中单宁 |
| 脆皮乳鸽 | 黑皮诺、桑娇维塞 |
| 白切鸡 / 油鸡 | 过桶霞多丽、绿维特利纳、黑皮诺 |
| 卤味拼盘 / 卤水 | 半干雷司令、啤酒、清酒 |
| 蜜汁烧鳝 / 烧鳗 | 半干雷司令、桃红（**水产本类不配重红**）|

⚠️ **别用重单宁配挂糖的烧味**：焦糖化的糖 + 重单宁 = 苦。想上红，选**果味主导、单宁轻**的。
⚠️ 烧味拼盘上桌时**一盘多味**：按「盘里最甜最油的那件」定酒，或直接上一白一红两杯。

### 点心 / 蒸点 / 肠粉 / 包点（v1.1 新增 · 早茶线）

**本类特征：一口一味、皮多馅少、冷热混桌、单份量小。** 原则：**按点心类型分流，别想着一瓶配全桌**；最省事的答案是**一白（干型）一红（轻果味）+ 起泡开场**。

| 点心 | 配什么 |
|---|---|
| 虾饺 / 烧卖 / 带子饺（鲜）| 干型雷司令、绿维特利纳、白中白香槟 |
| 叉烧包 / 流沙包 / 奶黄包（甜咸）| 半干雷司令、Moscato（流沙/奶黄）、果味红 |
| 小笼包 / 灌汤包 / 生煎 | 起泡、半干雷司令、干型雷司令 |
| 凤爪 / 排骨 / 金钱肚（酱蒸）| 半干雷司令、清酒、啤酒 |
| 肠粉（虾/牛/叉烧）| 干型雷司令、绿维特利纳；牛肉肠粉可上黑皮诺 |
| 蒸萝卜糕 / 芋头糕 / 煎糕 | 香槟、半干雷司令 |
| 春卷 / 炸物 / 咸水角 | 起泡、干型雷司令（气泡刷油）|
| 蛋挞 / 马拉糕 / 甜点 | Moscato d'Asti、甜白 |
| 粥 / 汤面 / 云吞面 | 清酒、干型雷司令、茶（见三节）|

⚠️ **点心桌最常见的错误**：拿一瓶重单宁红配全桌 —— 虾饺、肠粉、甜包全踩雷。**点心桌优先白 + 起泡**。
⚠️ **茶位同样是配酒**：点心配茶（普洱/乌龙）常比配酒更合适（见三节）。别因为「在酒单上」就只推酒。

## 三、非葡萄酒酒水（同样入清单）

| 类型 | 怎么用 |
|---|---|
| **清酒** | 日料首选；也适合清蒸鱼、白灼类 |
| **啤酒** | 拉格→炸物；小麦→海鲜/沙拉；IPA→辣/烧烤；世涛→甜点/巧克力 |
| **威士忌** | 高球配炸物；单一麦芽配烟熏/烤肉。⚠️ 配牛排其实不如红酒 |
| **鸡尾酒** | 餐前开胃 / 餐后消化；佐餐要低甜 |
| **香槟 / 起泡** | 万能开场：生蚝/炸物/开胃；⚠️ 不当牛排佐餐主力 |
| **无酒精 No/Low** | 选有酸度或苦度的（汤力水/气泡茶）；开车/孕妇/不饮酒客人的标配 |
| **茶** | 普洱→油腻；龙井→清蒸；乌龙→烧烤 |
| **加强酒 Port/Sherry** | 餐后 / 蓝芝士 / 甜点，不当主菜酒 |
| **咖啡** | 仅餐后；不配主菜（压味）|

⭐ 客人不喝葡萄酒时，上面的清单就是回答。**别因为"只有酒单"就只推酒。**

### 无酒精方案的最低配置（v1.1 新增）

不饮酒客人（开车 / 孕妇 / 忌酒 / 未成年）**必须能当场给出 3 个可选**，且**不能只是「白开水」**：

| 场景 | 给什么 | 上桌形态 |
|---|---|---|
| 配前菜 / 生食 | 气泡茶、汤力水（有酸/苦度）| 香槟杯，冰镇 |
| 配主菜（红肉类）| 无醇红、冷萃乌龙、洛神花 | 红酒杯 |
| 配点心 / 甜品 | 单枞、茉莉、无醇起泡 | 白杯 / 香槟杯 |
| 全程替代 | 无醇起泡（整瓶）| 全程同一杯型，与在座同节奏 |

⚠️ 无酒精也要**跟餐节奏换**（别一杯热水陪全程）；**先问、不反复劝**（见六节）。
⚠️ 收费与「是否算茶位」按本店配置，**交付前必须写清**（见十一节）。

## 四、套餐 / 宴席配酒设计

**一席多菜时，按"上酒节奏"排，不是每道菜单独配。**

1. **开场**：香槟/起泡 或 干型白 —— 配前菜/冷盘/生食
2. **中段（白）**：清蒸、白肉、海鲜、蔬菜
3. **中段（红一）**：轻单宁 —— 禽类、猪肉、蘑菇菜
4. **主菜（红二）**：重单宁 —— 红肉 / 牛排
5. **收尾**：甜酒（比甜点更甜）/ 加强酒；餐后咖啡

⭐ 款数经验：**四道以下用 2 款（一白一红）；五～八道用 3 款；正式宴席 4 款封顶。**
酒多了反而让客人记不住，也让上菜节奏乱。
⚠️ 每增一款就多一套杯 + 一个服务动作 → **先算人手与杯具够不够**。

### 台上量算法（v1.1 新增 —— 「先算人手与杯具」要能算出来）

| 要素 | 口径 |
|---|---|
| 每款酒杯数 | 按 **1 杯/款/人** 起算；正式宴席加 **0.5 杯续杯余量** → 每款 = 人数 × 1.5 |
| 杯具总数 | 款数 × 人数 × 1.5，**且总量多备 10%**（破损 / 串杯）|
| 侍酒动作 | 每款酒至少 **1 次巡回**；4 款 × 10 人 ≈ 40 杯 → 需 **2 名服务**配合（1 人 1 轮 ≤ 15 杯可保节奏）|
| 库存复核 | 杯型库存必须 ≥ 上述总数；**瓶颈杯型**（闻香杯、子弹杯等非常备杯型）单独核 |
| 温度准备 | 起泡/清酒需冰桶位；重红提前 30–60 分钟出窖回温 |

⚠️ **杯型库存不够时优先减款数，不要减每款杯数**（客人会觉得「这酒只给了一杯」）。

## 五、单杯酒单结构（by the glass）

**单杯不是为了省钱，是为了让客人能"一人一菜一酒"。**

选哪几款做单杯，四个判据：

1. **覆盖口味光谱**：白红至少各一；白要一清爽一丰满，红要一轻一重
2. **能配招牌菜**：先从菜单爆款反推该上哪几杯
3. **开瓶后保质期**：单杯酒开瓶后 2–3 天卖不完就亏（看酒种；气保鲜可延长）
4. **毛利不能倒挂**：单杯定价 ≈ 瓶价 ÷ 杯数 × 1.3–1.5（杯数按 5–6 算）

⚠️ 客人常以为所有酒都能单杯点 —— **推荐时必须主动说清哪款能单杯**，否则结单易争议。
⚠️ 套餐里若用单杯，要把服务费与开瓶损耗计入。

### 判据 3/4 的执行口径（v1.1 新增 —— 不给口径，这两条会被算歪）

**杯数怎么算**
- 葡萄酒 750ml ÷ 单杯 150ml = **5 杯**（标准）；经营惯例可倒 **6 杯**（每杯 ~125ml）
- 起泡因气泡损耗按 **5 杯**；甜酒 75ml/杯 → 按 **8–10 杯**
- **烈酒不适用这套公式**（威士忌/白兰地 700–750ml 按 **25–30 杯**算；套 5 杯会得出「越卖越亏」的荒谬结论）
- 黄酒 / 清酒按 **5–8 杯**；啤酒按**瓶**

**定价区间（等价写法，便于一眼判断）**
- 单杯价 = 瓶价 ÷ 杯数 × (1.3 ~ 1.5) ⟺ **瓶价 ÷ 杯价 ∈ 3.3 ~ 4.6**
- 瓶/杯比 **> 4.6** → 单杯定价偏低（开瓶卖不完成本风险）
- 瓶/杯比 **< 3.3** → 单杯定价偏高（客人会直接点整瓶）
- ⚠️ **这是毛利参考线，不是合规红线**。低于下限但属**主推 / 引流 / 高辨识度**款时是经营选择，**要在交付物里标注理由**，不要默默放过。
- 服务费与开瓶损耗是否计入杯价口径，**各店不同 → 交付时必须写明口径**（否则同一份数据两方算出的「越界」数量不一样）

**开瓶后保质期（经验值，各店以实测校准）**

| 酒种 | 可用天数 | 备注 |
|---|---|---|
| 起泡 / 香槟 | 1 天（气保鲜 2 天）| 失气最快 |
| 清爽干白（长相思/绿维特利纳/夏布利）| 1–2 天 | 冷藏 + 塞 |
| 过桶霞多丽 / 半干白 | 2–3 天 | |
| 轻红（黑皮诺/佳美）| 2 天 | |
| 中重红（赤霞珠/西拉/桑娇维塞）| 3–4 天 | 单宁抗氧化 |
| 甜酒 | 1–2 周 | 糖度高，抗氧化 |
| 加强酒（波特/雪莉）| 2–4 周 | |
| 清酒（开封）| 2–3 天 | 必须冷藏 |
| 黄酒 | 1–2 周 | 阴凉 |
| 烈酒 | 数月 | 不倒瓶 |

⭐ **开瓶临界点公式**：`单杯价 ≥ 瓶价 ÷ min(瓶容量÷杯量, 可售天数 × 日均杯数)`。算出来不成立的款，**不要拿来做单杯**（或改成整瓶 / 整壶售卖）。

⚠️ **一人一菜一酒才是单杯的真正目的**：上位菜（燕鲍参、花胶）份量小、单价高，**用单杯比开瓶合理**，这条最容易被忽略。

## 六、服务话术基调

- 先问「**您喜欢油香多点还是肉味重点**」，不要问「要贵的还是便宜的」
- **不给最贵的，给最配的**；客人点贵酒配错菜时，用"更配"而不是"不能"来引导
- 客人不喝酒 / 开车 / 孕妇：**直接给无酒精方案，不要反复劝酒**

### 可直接用的应答卡（v1.1 新增）

| 客人说 | 不这样说 | 这样说 |
|---|---|---|
| 「来瓶最贵的」| 「好的」（然后配错菜）| 「这瓶我更建议配您的××（主菜）；前面几道清蒸的，用一杯××会更配 —— 要一瓶还是一杯？」|
| 「随便配一下」| 全上重红 | 「您这桌清蒸和烧味各一半，我配一白一红，先上白的？」|
| 「我不喝酒」| 「那给您倒点果汁？」| 「我们有气泡茶和无醇起泡，用香槟杯上，跟大家的节奏一样」|
| 「红酒不是更高级吗」| 「红酒配鱼也可以的」| 「红酒配鱼会出铁锈味，这是单宁的化学反应；换成××，鱼的鲜甜会出来」|
| 「喝不完」| 「可以存」| 「这款能单杯点，先来两杯，够了再加」|
| 「这酒贵不贵」| 只报单价 | 「按杯点人均××；配您这桌四道菜刚好」|

## 七、⚠️ 本店配置（会变，用时先核）

> 本节是**配置层**，不是知识。换店 / 换季先核。

- **酒单在哪找**：向用户要**现行**酒单（含酒名 + 产地/品种 + 杯价/瓶价）；不要用旧版
- **成本 / 经销商列 = 内部敏感**：内部版可留，**对外 / 上公开站点必须剔掉**
- **⚠️ 多店运营时各店酒单绝不混用** —— 不同店是不同文件，别拿 A 店的酒配 B 店的菜
- 酒款名用**酒标原文**（中英对照）；价格标「以现行酒单为准」
- 本地禁忌与习惯以用户最新指示为准（例：某品牌黄酒已停推，改干白 / 轻红 / 清酒 / 香槟）
- 部位推荐熟度以**菜谱 / 培训手册底本**为准，**不得凭印象写**（见 `delegation-verification`）
- **本店口径三件套（v1.1）**：①杯价是否含服务费 ②单杯杯量（125 / 150 ml）③哪些款「可单杯」—— 这三条每次交付前确认一次，否则算出的「越界款」两方不一致

## 八、三个最容易推错的

- **贵 ≠ 配**。把最贵的香槟推给牛排是典型错误。
- **白葡萄酒不该推给牛排**。客人要"配得上"不是"贵"。
- **菲力比眼肉更生**（一～三分 vs 三～五分），最瘦的肉过熟就柴。

### v1.1 实测补充（把本 skill 拿到真实菜单与酒单上跑出来的）

- **重单宁红配「含虾蟹的辣菜」是高发错误**：实测某道「辣味禽肉 + 虾蟹 + 菌菇」的菜，官方配酒表却给了重单宁红 → 同时违反「单宁×鲜」与「重单宁×辣」两条硬规则。
- **香槟被推给红肉主菜**：点心 / 前菜桌用香槟没问题，**当主菜主力就是八节第一条错误**。
- **酱汁里的糖比肉本身更该定酒**（蜜汁 / 糖醋 / 辣椒酱）：只按「红肉 → 重单宁」会翻车。
- **官方配酒表的覆盖率可能很低**：实测某店 **100+ 道菜**的菜单，官方配酒只覆盖约 **1/4**；缺口集中在 海鲜 / 蒸点 / 烧味 / 汤羹 / 燕鲍参 —— 这正是 v1.1 补三章的原因。
- **三源价格真会不一致**：实测同一款饮品，内部成本表与客人版**价差可达一倍以上**。**洗数据时必须两两比对**。

## 十、输入数据规范（v1.1 新增 —— 拿到的文件先过这一关）

**最低字段集**（缺哪列先补，不要凭经验猜）

| 文件 | 必需字段 |
|---|---|
| 菜单 | 菜名（中）/ 英文名 / **主料** / 味型或口味 / 菜段分类 / 是否位上 |
| 酒单 | 酒名原文（中 + 英）/ 酒种类型 / 产地或品种 / **杯价** / **瓶价** / 是否可单杯 |
| 内部版附加 | 成本 / 成本率 / 经销商（**对外必剔**）|
| 配套 | 杯型表（杯名 - 容量 - 库存）/ 配酒指针表（酒 → 菜）|

**拿到文件先跑 6 项校验**（这 6 项都是实战踩出来的）

1. **分隔符陷阱**：菜名与英文名常是**单元格内换行**（不是 `/`、不是 `、`），主料列同理 → 先按换行切，再按 `/` 兜底
2. **两行一款**：酒单成本表常见「英文名行 + 中文名/规格行」交错 → 按行对解析，别按列直读
3. **合并单元格 / 内嵌图**：`DISPIMG` 公式与合并格会让「菜名」落在上一行 → 逐行建块，不假设一对一
4. **指针死链**：配酒表「搭配菜品」列会有 ①占位符 `—` ②菜已下架 ③名字对不上（如配酒表写「X 藕饼」、菜单写「香酥 X 饼」）→ 清洗必须分出 **精确 / 近似 / 多义 / 悬挂** 四类，逐条列明
5. **跨表重复**：同一道点心常同时出现在「点心」与「主食&点心」两表 → 去重后再统计覆盖率，否则分母虚高
6. **三源价格比对**：内部总表 / 客人版 / 成本表 三处价必须两两比 —— 实测真出过同一款饮品两个价（差一倍以上）

**清洗产出标准**：`dishes`（含派生属性）/ `wines`（含酒型·单宁·甜度·酸度·是否过桶）/ `pairings`（四类状态）/ `glassware` / 内部版（含成本率）**各一份，全部落表、可复核**。

## 十一、交付前自检清单（v1.1 新增 —— 交付物做完必过一遍）

- [ ] **1 名称悬挂 = 0**：每条配酒指针都能指到现行菜单上的真实菜名（近似 / 多义必须人工确认）
