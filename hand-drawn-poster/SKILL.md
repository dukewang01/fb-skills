# 手绘感海报 / 图版

把「干净的矢量图」变成「人手画的」——靠四件事，不靠手写字体。
风格基准样例：`~/.hermes/tmp/hd_a.html`（熟度剖面）、`hd_b.html`（牛体部位）、`steak_geo.html`（手绘地图）。

## 风格契约（成套使用，别只拿一半）

- 底色米黄 `#f7f4ea` + 22px 细网格；再叠一层 SVG `feTurbulence` 噪点（data-URI 背景，`baseFrequency=0.85`，alpha 斜率 0.06）→ 纸感
- 主色：正红 `#b5432f`（标题虚线框 / 图钉）、深褐 `#6d2f26`（描边）、卡片米白 `#fffdf6`、虚线边框 `#cbc2ae`
- 标题：31px，`inline-block`，2.4px 虚线边框，`rotate(-.5deg)`，浅底 `#fdfaf2`
- 卡片：`#fffdf6` + 1.8px dashed + 圆角 5px + `box-shadow:1.8px 2.4px 0 rgba(140,120,85,.14)`，**每张随机 `rotate(-0.6~0.6deg)`**
- 装饰物（手账的真家伙，必放）：回形针（圆角矩形 + `border-bottom-color:transparent`）、订书钉（倒 U + 两条小腿）、胶带、红色图钉
- 强调：`#f6e6a8` 底 + 圆角 3px

## 「手绘」只能做在线条/框/底纹上

没有中文手写体时（Termux 只有 Noto Sans CJK），**字还是黑体**。手绘感全部来自：
1. **抖动描边**：图形轮廓按边细分 3 段 + 随机偏移（±2~4px），**同一条边画两笔错开**（一实一淡）→ 模拟笔尖来回
2. **微歪**：卡片/便签随机旋转 ±0.5~0.8°，不要一字排开
3. **纸纹**：噪点 + 网格，两层叠加
4. **实物点缀**：图钉/回形针/订书钉/胶带 —— 这些比画得像更能出「手账」味

⚠️ **随机必须固定种子**（如 `random.seed(20261010)`），否则每次生成都不一样，用户会以为坏了。

## 渲染管线（Termux 无头 Chromium）

```
chromium-browser --headless --no-sandbox --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=2 --window-size=1587,H --screenshot=/abs/path.png file:///abs/path.html
```
- `--screenshot=` 与路径**必须同一参数**，空格分开会静默失败
- 窗口高度给足；高度不够会把内容裁掉，**不会报错**
- 裁剪：取右下角像素当背景色，按行/列墨迹阈值取边界
  - ⚠️ **裁剪框必须 clamp 到画布内**（`min(cols[-1]+pad, W)`），否则 PIL 越界补**纯黑边**
- 出 A3 PDF：`FPDF(unit='mm', format=(297,420))`，**不要传 orientation**（传了会变横版）；算 `s=min((W-10)/iw,(H-10)/ih)` 居中贴图
- 出稿**必须量** `mediabox` 确认尺寸，不能只看代码；裁剪后**必须检查最右/最上/最下像素不是纯黑**

## 自检纪律

- **低分辨率读图会编造文字**：整页缩放后识别出的字串，源文件里可能根本不存在。判断图上有没有某个元素，用**原分辨率分区**看，或用**精确颜色像素统计**（某个色值的像素数 > 0 即在位）；不要拿缩放后的视觉结论当证据
- 交出去前量：像素尺寸 + 每处装饰的色值像素数 + PDF MediaBox
- 图不像（比如手画的动物）要**主动告诉用户**，并给出更稳的替代画法
- 本机**无出网**：需要网络素材（地图底图、图库）时不要试下载，直接自绘或改用已有素材
