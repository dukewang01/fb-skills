# 宣传禁用语完整词表（七类）

> 逐字比对菜单/台卡/宴会菜单/BEO/送餐单/宣传文案。英文字面同理（exclusive / best / No.1 / the finest）。
> 来源：集团 SOP《菜单描述-合规审查清单》第 13 项，共七类。

## 一、表示权威性的禁忌词
国家 XX 领导人推荐、国家 XX 机关推荐、专供、特供（及"XX 专供"）、质量免检、无需国家质量检测、免抽检、人民币图样（央行批准除外）、老字号、中国驰名商标

## 二、含"首/家/国"及相关词语
首个、首选、全球首发、全国首家、全网首发、首款、首家、独家、独家配方、全国销量冠军、国家级产品、国家（国家免检）、国家领导人、国宴、填补国内空白

## 三、含"最"及相关极限词语
最、最佳、最具、最爱、最赚、最优、最先进、最优秀、最好、最大、最大程度、最高、最高级、最高档、最奢侈、最低、最低级、最低价、最底、最便宜、时尚最低价、最流行、最受欢迎、最时尚、最聚拢、最符合、最舒适、最先、最先进科学、最先进加工工艺、最先享受、最后、最后一波、最新、最新科技、最新科学

## 四、含"一"及相关极限词语
第一、中国第一、全网第一、销量第一、排名第一、唯一、第一品牌、NO.1、TOP.1、独一无二、全国第一、一流、**一天**、**仅此一次（一款）**、**最后一波**、**全国 X 大品牌之一**

## 五、含"级/极"及相关词语
国家级（相关单位颁发证书的除外）、全球级、宇宙级、世界级、顶级（顶尖/尖端）、顶级工艺、顶级享受、极品、极佳（绝佳/绝对）、终极、极致

## 六、表示绝对、极限且无法考证的词语
绝对值、绝对、大牌、精确、超赚、领导品牌、领先上市、巨星、著名、奢侈、世界/全国 X 大品牌之一、世界级、金牌、名牌、优秀、世界领先、顶级工艺、王牌、销量冠军、极致、永久、掌门人、领袖品牌、绝无仅有、史无前例、万能、**100%**、国际品质、高档、正品

## 七、虚假内容相关词语
史无前例、前无古人、永久、万能、祖传、特效、无敌、**纯天然无污染**

> **注意近似词**：以上均为列举，**含义相同或近似的绝对化用语同样违规**。例如"顶级"要按第五类与第六类同时考量；"100%""纯天然"无法举证时按第六/七类处理。

## 替换词对照（给具体词，不停在"不合规"）
| 方向 | 原文 | 建议用词 |
|---|---|---|
| 最类 | 最新鲜 | 每日鲜达 / 当日直送 |
| 最类 | 最好吃 | 招牌风味 / 主厨推荐 |
| 最类 | 最受欢迎 | 客人常点 / 热销 |
| 首/独家 | 独家配方 | 本店配方 |
| 一/唯一 | 全城唯一 | 本店特色 |
| 权威 | 特供 / 专供 | 直接删除 |
| 认证 | 有机（无证明） | 删除或补认证文件 |
| 野生 | 野生大黄鱼 | 生态养殖大黄鱼（附证明） |
| 五/六类 | 顶级 | 高品质 / 精选 |
| 五/六类 | 极品 | 甄选 |
| 六类 | 著名 | 口碑之选（有依据时） |
| 六类 | 100% | 如实标注具体含量，或删除 |
| 七类 | 纯天然无污染 | 无添加（须有证明，否则删除） |
