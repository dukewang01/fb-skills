# 菜单合规 · 通用原则（适用任何酒店主体）

> 使用前提：集团/品牌 SOP 只在其成员酒店内有效。本文件把 SOP 拆成两层：
> **A 层 = 国家法规与行业刚性要求（任何酒店都适用）**；**B 层 = 集团内部流程（换成本酒店自己的即可）**。
> 审查别家店的菜单时，只套 A 层；内部流程按对方制度替换。

## A 层 · 刚性红线（任何主体，逐条必查）

| # | 检查点 | 依据 |
|---|---|---|
| A1 | 不得添加药品及**非药食同源**物质（对照药食同源目录） | 《食品安全法》 |
| A2 | 不得宣称**疾病预防、治疗、疗效、保健功能** | 《广告法》《食品安全法》 |
| A3 | 无**有机／绿色／无公害**证书不得宣称 | 《认证认可条例》《广告法》 |
| A4 | 不得使用 **HALAL／清真、犹太** 认证标识（改事实性说明） | 食品标识与广告管理 |
| A5 | **产地、级别**须与事实相符，须有证明文件 | 《广告法》虚假宣传条款 |
| A6 | 不得含**非食用物质**（金箔金粉、银箔银粉、亚硝酸盐等） | 《食品安全法》 |
| A7 | 不得以**野生动物**为食材，不得代客加工 | 《野生动物保护法》 |
| A8 | 禁购／售／宣传**长江及长江流域保护区、干流、重要支流、通江湖泊等重点水域**水产品 | 长江保护法及禁捕规定 |
| A9 | **河鲀**：禁野生；禁养殖活鱼与未加工整鱼；批准品种须标"人工养殖" | 食品安全与渔业规定 |
| A10 | 须有**过敏原提示**（菜单、档口、站点均有意义；自助餐尤其必要） | 餐饮服务通用要求 |
| A11 | **特殊食材**（桃胶、虫草花、党参、西洋参等）须标"不宜食用人群＋食用量" | 药食同源管理 |
| A12 | **宣传禁用词七类**（权威类／首·家·国类／最类／一类／级·极类／绝对类／虚假内容类） | 《广告法》《反不正当竞争法》 |

### A12 的七类（逐字比对，中英同步）
1. **权威性**：国家领导人/机关推荐、专供、特供、质量免检、免抽检、人民币图样、老字号、中国驰名商标
2. **首／家／国**：首个、首选、全球首发、全国首家、全网首发、首款、独家（配方）、全国销量冠军、国家级产品、国宴、填补国内空白
3. **最类**：最、最佳、最优、最好、最大、最高、最低、最便宜、最流行、最受欢迎、最新、最后…及同义近义绝对化用语
4. **一类**：第一、全网第一、销量第一、排名第一、唯一、NO.1、TOP.1、独一无二、一流、一天、仅此一次、全国 X 大品牌之一
5. **级／极类**：国家级（有证书除外）、全球级、宇宙级、世界级、顶级、顶级工艺、顶级享受、极品、极佳、终极、极致
6. **绝对／无法考证类**：绝对、大牌、精确、超赚、领导品牌、著名、奢侈、金牌、名牌、优秀、世界领先、王牌、销量冠军、永久、掌门人、领袖品牌、绝无仅有、万能、100%、国际品质、高档、正品
7. **虚假内容类**：史无前例、前无古人、永久、万能、祖传、特效、无敌、纯天然无污染

> **近似词同罚**：以上为列举，含义相同或近似的表述同样违规。"顶级"按第 5、6 类同时考量；"100%""纯天然"无法举证按第 6、7 类处理。
> **英文同样要查**：exclusive / best / No.1 / the finest / premium / top-grade。

## B 层 · 内部流程（换成本酒店自己的）

| 集团 SOP 的写法 | 通用替换方式 |
|---|---|
| 在集团食品安全系统创建审阅任务 | 换成本酒店自己的审阅工单／OA 流程 |
| 集团大学课程 877301 必修 | 换成本酒店／管理公司自己的培训科目与台账 |
| 四签：提交人 / 卫生经理 / 行政总厨 / 餐饮总监 | 按自身组织架构签署（如行政总厨／餐饮经理／食品安全员／店总） |
| 有食品供应的站点摆放防过敏警语标识牌 | **实质是行业好实践，建议保留**（A10 已覆盖） |
| 特殊食材联系卫生官确认 | 换成食品安全员／属地市场监管口径 |

## 判定与输出纪律（不分主体，一律适用）
- **误报比漏报更伤信任**：拿不准标 🟠"需确认"，不写 🔴"违规"。
- **必须给具体替换词**，不停在"不合规"。
- **看语境**：菜名 vs 宣传语风险不同，但一律要报，用级别区分。
- **双语菜单双语都查**，中英不对齐也是问题。
- **禁令词表必须读到底**：七类，只看到四类会漏掉后三类。
- **审查对象范围**：菜单、台卡、宴会菜单、BEO、送餐单、广告宣传、线上文案、礼盒说明。
