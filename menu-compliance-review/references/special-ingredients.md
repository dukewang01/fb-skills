# 特殊食材与药食同源判定口径

## 必须标注"不宜食用人群 + 食用量"的食材
文档列举（**非完整清单**，不确定一律交卫生官）：**桃胶、虫草花、党参、西洋参**

标准标注句：
> 婴幼儿、孕妇和哺乳期妇女人群不宜食用，推荐食用量 ≤ XX 克/天

## 判定口径
1. 属**中药材/药食同源**范畴的配料，先查《药食同源清单》：
   - 清单内 → 可用，视情况标注食用人群与食用量
   - 清单外 → 🔴 不得出现在菜单上
   - 拿不准 → 🟠"需卫生专员确认"
2. 高风险区：**中式汤品、养生炖品、凉茶、药膳套餐、节令礼盒**
3. 同一食材在**菜品正文**与**宣传语**都要审（宣传语写"滋补养生"即触第 2 条疗效宣称）

## 同时要查的两张禁单
- **非食用物质**：金箔金粉、银箔银粉、亚硝酸盐等 → 🔴
- **禁捕水域水产品**：长江及长江流域保护区、干流、重要支流、通江湖泊等重点水域 → 🔴（含"宣传"，图片也不行）
